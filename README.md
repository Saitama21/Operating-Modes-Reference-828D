# Operating Modes Reference 828D

Первая рабочая сборка личного офлайн-справочника проверенных режимов обработки для SINUMERIK 828D. База запускается пустой: материалы доступны сразу, а записи появляются только после того, как пользователь добавит свои реальные режимы.

## Что уже работает

- полноэкранный mobile-first интерфейс без вертикального скролла на основных экранах;
- Material Carousel с цветовым кодированием материалов;
- фоновая подсветка карточек в стиле ambient / Liquid Glass;
- отдельный экран материала и перелистывание записей стрелками;
- поля: деталь, Ø заготовки, операция, обороты, подача, глубина, инструмент;
- необязательная заметка;
- прикрепление фотографии;
- добавление, редактирование и удаление записей;
- поиск по деталям, материалам, операциям, инструменту и заметкам;
- локальное хранение в IndexedDB — без аккаунта и синхронизации;\n- чистый старт без демо-записей и выдуманных режимов;
- экспорт/импорт JSON для резервной копии;
- PWA manifest + Service Worker для офлайн-работы;
- GitHub Pages workflow.

## Материалы первой сборки

AISI 304, Сталь S355, Полиамид PA6, Латунь CuZn37, Титан Ti6Al4V, Алюминий Al 6061.

## Архитектура

Чистые HTML/CSS/JavaScript без фреймворков и внешних зависимостей. Приложение рассчитано на GitHub Pages и работает полностью на устройстве пользователя.

Основной dock закреплён за viewport приложения. Safe Area используется только как внутренний отступ dock/topbar.

## Данные

Пользовательские записи находятся в IndexedDB текущего браузера/установленной PWA. Для переноса между устройствами используется JSON Export / Import.
